# Elawaady XDigital Platform Store

مشروع متجر خدمات رقمية PHP + MySQL مبني على هيكل أقسام المتجر.

## الملفات الأساسية

- `index.php` الصفحة الرئيسية
- `categories.php` عرض الأقسام الرئيسية
- `subcategories.php` عرض الأقسام الفرعية والخدمات التابعة
- `service.php` صفحة تفاصيل الخدمة
- `search.php` صفحة البحث
- `contact.php` صفحة التواصل
- `db_connect.php` اتصال قاعدة البيانات
- `database.sql` إنشاء قاعدة البيانات والجداول والبيانات الأولية
- `assets/css/style.css` تنسيق الواجهة
- `assets/js/main.js` جافاسكريبت بسيط للقائمة

## طريقة التشغيل على cPanel

1. ارفع ملفات المشروع داخل `public_html`
2. افتح phpMyAdmin
3. أنشئ قاعدة بيانات باسم `elawaady_store`
4. اعمل Import لملف `database.sql`
5. عدّل بيانات الاتصال داخل `db_connect.php`
6. افتح الدومين
